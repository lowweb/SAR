# SAR — Система учёта оборудования

Веб-приложение для учёта движения компьютерной и оргтехники с штрих-кодами.

## Стек

- **Frontend:** Vue 3 + Pinia + Vue Router + Bootstrap 5 + JsBarcode
- **Backend:** Node.js + Express + SQLite (better-sqlite3)
- **Auth:** JWT

## Запуск

### Production (сборка)
```bash
cd client && npm run build && cd ..
npm run start
```
Откройте http://localhost:3000

### Development
В двух терминалах:
```bash
# Терминал 1: backend
npm run server

# Терминал 2: frontend (dev server с прокси)
npm run client
```
Frontend: http://localhost:5173
Backend: http://localhost:3000

## Функционал

### Пользователь
- Просмотр списка своего оборудования
- Фильтрация и поиск оборудования
- Просмотр детальной информации и штрих-кода
- Просмотр истории перемещений
- Добавление нового оборудования

### Администратор
- Все возможности пользователя
- Просмотр оборудования всех пользователей с выбором пользователя
- Редактирование оборудования
- Перемещение оборудования между пользователями и смена статусов
- Редактирование записей истории перемещений
- Управление справочниками: пользователи, департаменты, типы оборудования, статусы
